# ✅ Todo Application

A clean and responsive **Todo App** built with **HTML5, CSS3, and JavaScript** with a Java-powered backend logic concept.

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox, Gradients, Animations)
- JavaScript (DOM Manipulation, Array Methods)

## ✨ Features
- ➕ Add tasks with **priority levels** (High / Medium / Low)
- ✅ Mark tasks as **completed**
- 🗑️ Delete individual tasks
- 🔍 **Filter** tasks — All / Pending / Completed
- 📊 Live **task stats** (Total, Pending, Completed)
- 🧹 Clear all completed tasks at once
- ⌨️ Press **Enter** to quickly add tasks
- 📱 Fully **responsive** design

## 🚀 How to Run

No installation needed!

```bash
# 1. Clone the repository
git clone https://github.com/niharika2588/todo-app.git

# 2. Navigate to the folder
cd todo-app

# 3. Open index.html in your browser
# Just double-click index.html OR drag it into Chrome/Firefox
```
